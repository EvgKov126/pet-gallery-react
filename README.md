### Практична робота №6: Хук useEffect та робота з локальним сховищем (localStorage)

**Тема роботи:** Керування побічними ефектами за допомогою хука `useEffect` та забезпечення тривалого зберігання даних у браузері (Data Persistence).

**Мета роботи:** Навчитися використовувати хук `useEffect` для синхронізації стану застосунку із зовнішніми джерелами (localStorage), реалізувати автоматичне збереження та завантаження даних, а також оптимізувати процес ініціалізації стану за допомогою лінивих обчислень (Lazy Initializer).

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19

#### Основні досягнення в цій роботі:

1.  **Автоматичне збереження даних (`useEffect`):**
    *   Реалізовано ефект, який відстежує будь-які зміни в масиві `pets` (додавання нової тварини або зміна статусу "лайка").
    *   При кожному оновленні списку дані автоматично серіалізуються в JSON та записуються в `localStorage` під унікальним ключем `pet-gallery-data`.

2.  **Оптимізоване завантаження (Lazy State Initializer):**
    *   Замість завантаження в окремому `useEffect`, використано функцію ініціалізації в `useState`.
    *   Це дозволяє зчитувати дані з `localStorage` лише один раз — під час першого рендеру компонента `App`, що запобігає зайвим операціям читання та ререндерам.

3.  **Динамічна статистика в реальному часі:**
    *   Додано інтерактивний лічильник улюбленців у `Header`, який миттєво реагує на дії користувача та зберігає актуальне значення навіть після закриття браузера.

4.  **Покращений зворотний зв'язок (Empty States):**
    *   Система повідомлень у компоненті `PetList` тепер адаптується до обраного фільтра. Якщо у вкладці "Тільки улюблені" немає відмічених карток, користувач отримує відповідну підказку, що покращує UX.

5.  **Зміна пріоритету після створення:**
    *   Доопрацьовано механізм додавання нових мешканців: впроваджено сувору перевірку на невід’ємний вік та обов’язкову наявність URL-адреси фотографії, що гарантує цілісність збережених даних.

#### Попередньо реалізований функціонал (Практична робота №5):
*   Керована форма додавання улюбленців із використанням `datalist` для вільного введення виду тварини.
*   Система "лайків" із використанням SVG-іконок та динамічною зміною стилів карток.
*   Фільтрація списку (Усі / Улюблені) на основі стану `isLiked`.
*   Повна підтримка імутабельності стану при оновленні масиву через оператор `spread`.

#### Архітектурна схема потоку даних:
`App State` (pets) ↔ `localStorage` (синхронізація даних)
`App State` → `Header` (лічильник вподобань)
`App State` → `Main` → `PetList` → `PetCard` (відображення та взаємодія)


## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
