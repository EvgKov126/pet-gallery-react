### Практична робота №5: Робота з формами, керовані компоненти та маніпуляція станом у React

**Тема роботи:** Створення інтерактивних форм, обробка подій та динамічне оновлення списку даних у React.

**Мета роботи:** Отримати практичні навички створення керованих компонентів (controlled components), обробки подій відправки форми, валідації введених даних, а також реалізації функціоналу додавання та видалення елементів зі стану (state).

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19

#### Основні досягнення в проєкті:

1.  **Керована форма додавання улюбленців (`AddPetForm`):**
    *   Використано хук `useState` для синхронізації значень полів форми (`input` для імені, віку та URL-фото; `datalist` для виду тварини) зі станом React.
    *   Реалізовано обробник `handleSubmit`, який запобігає перезавантаженню сторінки (`preventDefault`) та збирає дані в єдиний об'єкт.
    *   Після успішного додавання реалізовано автоматичне скидання всіх полів форми до початкового стану.

2.  **Валідація та безпека даних:**
    *   Впроваджено перевірку на порожні поля за допомогою методу `.trim()`, що запобігає додаванню некоректних записів.
    *   Реалізовано контроль числового значення віку: використання атрибута `min="0"` у JSX та додаткова логічна перевірка в JavaScript, щоб унеможливити введення від’ємних значень.

3.  **ДинаДинамічне керування колекцією (CRUD - Create/Read):**
    *   **Додавання:** Нові картки тварин додаються до масиву `pets` у головному компоненті App через функціональне оновлення стану `setPets(prev => [...prev, newPet])`. Це гарантує імутабельність і коректну роботу React.
    *   **Унікальність:** Для кожного нового елемента генерується унікальний ідентифікатор за допомогою `Date.now()`, що забезпечує стабільну роботу атрибута `key` у списках.

4.  **Гнучкість введення даних (User Experience):**
    *   Замість жорсткого вибору (`select`) впроваджено елемент `<datalist>`. Це дозволяє користувачеві як обирати серед популярних видів (Собака, Кішка, Хом'як), так і вписувати власні унікальні варіанти (наприклад, "Капібара").

5.  **Інтеграція з медіа-контентом:**
    *   Реалізовано можливість додавання реальних зображень через поле введення URL-адреси. Нові картки одразу відображаються з відповідними фото, підтримуючи загальну стилістику галереї.

6.  **Зв'язність інтерфейсу та станів:**
    *   Новостворені картки миттєво стають частиною загальної екосистеми додатку: їх можна лайкати, вони враховуються загальним лічильником у `Header` та піддаються фільтрації (Усі / Улюблені), реалізованій у попередніх роботах.

#### Архітектурна схема потоку даних:
`AddPetForm` (введення та валідація) → `handleAddPet` (callback) → `App` (центральний стан) → `Main` → `PetList` → PetCar`d (відображення)


## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
