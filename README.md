# Практична робота №3 — Керування локальним станом

Ця робота присвячена вивченню механізмів керування станом у React за допомогою хука `useState`. Ми перетворюємо статичний список задач на динамічний, що дозволяє користувачу взаємодіяти з інтерфейсом.

## Що змінилося порівняно з Практичною роботою №2

| Характеристика | Практична робота №2 | Практична робота №3 |
| :--- | :--- | :--- |
| **Дані** | Статичні (звичайний масив) | Динамічні (стан `useState`) |
| **Зберігання** | Масив у `App` | Стан у `App` |
| **Взаємодія** | Лише `props` (відображення) | Події (onChange, onClick) та зміна стану |
| **Інтерфейс** | Тільки читання | Реально змінюється при взаємодії |

## Мета

- Ознайомитися з поняттям "стан" (state) у React та хуком `useState`.
- Навчитися передавати функції-обробники подій через `props`.
- Реалізувати інтерактивність: зміна статусу задачі, видалення або додавання нових елементів.
- Розуміти процес перерендерінгу компонента при зміні стану.

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19

## Структура та ієрархія компонентів (ЛР3)

Дані та функції для їх зміни передаються зверху вниз:

```
App (керує станом pets через useState)
├─ Header (отримує likedCount для відображення статистики)
├─ Main (прокидає масив pets та функцію handleToggleLike далі)
│  └─ PetList (ітерує масив та прокидає callback-функцію у кожну картку)
│       └─ PetCard (овідображає стан isLiked та викликає функцію зміни стану при кліку)
└─ Footer (відображає статичну інформацію про автора)
```

## Ключові етапи реалізації

### 1. Передача даних з App
У компоненті `App.jsx` створено масив об’єктів `PET_DATA`. Він передається в компонент `Main` як пропс: `<Main pets={PET_DATA} />`. Також демонструється передача простого рядка в `Header` та `Footer`.

### 2. Компонент-посередник Main
Компонент `Main` приймає `pets` через деструктуризацію параметрів і без змін передає їх у `PetList`. Це типовий приклад "прокидання" (drilling) даних.

### 3. Рендеринг списку в PetList
Тут використовується метод `map()`. Кожен елемент масиву перетворюється на компонент `PetCard`. Важливо: кожному `PetCard` передається унікальний `key={pet.id}` для коректної роботи React з DOM.

### 4. Відображення в PetCard
Компонент отримує конкретні властивості (`name`, `species`, `age`, `imageUrl`). Він використовує їх для:
- Відображення імені та породи улюбленця.
- Рендерингу зображення через атрибут src.
- Виводу віку тварини у відповідному блоці картки.

## Результати
Після виконання роботи застосунок стає динамічним: інтерфейс будується на основі даних, а не жорстко прописаного HTML. Це готує базу для впровадження стану (`state`) у наступних лабораторних роботах.


## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
