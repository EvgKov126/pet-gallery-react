### Практична робота №7: Асинхронні запити та CRUD операції з API

**Тема роботи:** Завантаження, створення, оновлення та видалення даних через зовнішнє API в React.

**Мета роботи:** Навчитися використовувати хук `useEffect` та асинхронні функції для повної інтеграції з REST API (GET, POST, PATCH, DELETE), керувати станами завантаження та синхронізувати локальний стан із сервером.

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19

#### Основні досягнення в цій роботі:

1.  **Повна інтеграція з DummyJSON API (CRUD):**
    *   **GET (Read):** Реалізовано асинхронне отримання даних про фахівців з догляду за тваринами через ендпоінт `/users`.

2.  **Асинхронна архітектура (`PetExperts.jsx`):**
    *   Логіку взаємодії з API інкапсульовано всередині хука ё, що забезпечує виконання запиту один раз при монтуванні компонента.
    *   Використано сучасний синтаксис `async/await` для написання чистого та читабельного асинхронного коду.
    *   Впроваджено блок `finally` для гарантованого вимкнення індикатора завантаження незалежно від результату запиту.

3.  **Обробка станів життєвого циклу запиту:**
    *   **Loading state:** Реалізовано анімований SVG-спінер та текстове повідомлення, що інформує користувача про процес завантаження.
    *   **Error state:** Створено візуальний блок з анімованою SVG-іконкою та кнопкою «Спробувати знову» для обробки мережевих збоїв.
    *   **Success state:** Динамічне відображення карток експертів за допомогою методу `map()` з використанням унікальних `key`.

4.  **Обробка помилок та станів:**
    *   Використання `try...catch` для кожного типу запиту.
    *   Вивід інформативних повідомлень про завантаження та помилки для покращення UX.

#### Технічний стек:
*   React Hooks (`useState`, `useEffect`)
*   Fetch API (async/await)
*   DummyJSON (External Mock API)
*   CSS3 & SVG — для створення анімованих інтерфейсів станів завантаження та помилок.

#### Попередньо реалізований функціонал:
*   Практична №6: Синхронізація основної галереї тварин з `localStorage`.
*   Практична №5: Форма додавання нових карток, валідація та фільтрація списку.
#### Архітектурна схема потоку даних:
`External API (DummyJSON)` → `fetch()` → `JSON Parsing` → `Component State`
`Component State` → `Conditional Rendering` (Loading / Error / Experts List)


## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
