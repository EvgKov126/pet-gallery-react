### Практична робота №8: Клієнтська маршрутизація в React

**Тема роботи:** Організація багатосторінкового інтерфейсу застосунку за допомогою React Router.

**Мета роботи:** Навчитися реалізовувати Single Page Application (SPA) архітектуру, налаштовувати декларативну маршрутизацію, працювати з динамічними параметрами URL та створювати зручну систему навігації без перезавантаження сторінки.

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19
- React Router 7

#### Основні досягнення в цій роботі:

1. 1. **Інтеграція React Router:**
   * Застосунок обгорнуто в `BrowserRouter` для підтримки History API.
   * Використано компоненти `Routes` та `Route` для побудови ієрархії сторінок.

2. **Архітектура сторінок як самостійних компонентів:**
   * **HomePage:** Презентаційна сторінка з Hero-секцією та інтерактивними елементами.
   * **PetsPage:** Центральний вузол галереї, що об'єднує форму додавання, фільтрацію та список карток.
   * **AboutPage:** Інформаційний блок з описом використаних технологій та метаданими розробника.

3. **Динамічна маршрутизація (`PetDetailsPage`):**
   * Реалізовано маршрут із параметром `:id` для перегляду детальних характеристик кожного улюбленця.
   * Використано хук `useParams()` для вилучення ID з URL та синхронізації з локальним станом даних.
   * Впроваджено захисну логіку (Error Handling) для випадків, коли елемент із вказаним ID відсутній у базі.

4. **Клієнтська навігація та UX:**
   * **Header:** Навігаційне меню побудоване на базі `NavLink`, що забезпечує автоматичну стилізацію активних маршрутів.
   * **PetCard:** Додано інтерактивне посилання «Детальніше» через компонент `Link`.
   * **NotFoundPage (404):** Реалізовано обробку неіснуючих маршрутів за допомогою шаблону `path="*"`, що включає візуальне попередження (SVG-знак) та можливість швидкого повернення на головну.

5. **Модульність стилів:**
   * Кожна сторінка отримала власний ізольований CSS-файл (`HomePage.css`, `PetsPage.css`, `PetDetailsPage.css` тощо), що запобігає конфліктам стилів.

#### Технічний стек:
* **React Hooks:** `useState`, `useEffect`, `useParams`
* **Router Lib:** `react-router-dom`
* **Icons:** Векторна графіка (SVG) для іконок попередження та вподобань.
* **Storage:** `localStorage` для персистентності даних між сесіями.

#### Попередньо реалізований функціонал:
* **Практична №7:** Асинхронна взаємодія з DummyJSON API.
* **Практична №6:** Керування локальним сховищем.
* **Практична №5:** Валідація форм та фільтрація списків.

#### Архітектурна схема потоку даних:
`External API (DummyJSON)` → `fetch()` → `JSON Parsing` → `Component State`
`Component State` → `Conditional Rendering` (Loading / Error / Experts List)


## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
