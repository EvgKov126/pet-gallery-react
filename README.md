### Практична робота №9: Керування глобальним станом за допомогою Context API

**Тема роботи:** Організація спільного доступу до даних у застосунку за допомогою React Context та реалізація динамічної зміни тем.

**Мета роботи:** Навчитися використовувати Context API для уникнення "prop drilling", створювати кастомні хуки для доступу до глобального стану, працювати з `localStorage` для збереження налаштувань користувача та реалізовувати адаптивний дизайн за допомогою CSS-змінних.

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19
- React Router 7

#### Основні досягнення в цій роботі:

1. **Впровадження Context API (`ThemeContext`):**
   * Створено глобальний контекст для керування темою застосунку (світла/темна).
   * Реалізовано компонент-провайдер `ThemeProvider`, що огортає застосунок та забезпечує доступ до стану теми в будь-якому компоненті.
   * Налаштовано синхронізацію стану з атрибутом `data-theme` тегу `<html>` для миттєвого оновлення CSS-змінних.

2. **Персистентність налаштувань через LocalStorage:**
   * Інтегровано роботу з `localStorage` для збереження обраної теми між сесіями користувача.
   * Реалізовано логіку ініціалізації, яка автоматично підтягує попередні налаштування при завантаженні сторінки.

3. **Розробка кастомних хуків:**
   * Створено хук `useTheme`, який спрощує споживання контексту та включає перевірку на наявність провайдера (Error Boundaries).

4. **Глобальна стилізація та Dark Mode:**
   * Проєкт повністю переведено на **CSS-змінні** (Custom Properties), що дозволило керувати всією палітрою з одного місця.
   * Реалізовано глибоку темну тему "Морська глибина" (Deep Blue).
   * Впроваджено сучасні ефекти дизайну: **Glassmorphism** (напівпрозорість + blur) для карток експертів та фільтрів.

5. **Покращення інтерфейсу та іконографіки:**
   * Замінено текстові емодзі на динамічні **SVG-іконки** (Сонце/Місяць).
   * Використано CSS-фільтри (`invert`, `brightness`, `drop-shadow`) для адаптації чорного логотипу під темний фон без зміни вихідного файлу.
   * Оновлено стилі лічильник

#### Технічний стек:
* **React Context:** `createContext`, `useContext`.
* **Hooks:** `useState`, `useEffect`, `useTheme` (custom).
* **Styling:** CSS Variables, Flexbox/Grid, Backdrop-filter.
* **Icons:** Векторна графіка (SVG).

#### Архітектурна схема потоку даних:
`ThemeProvider` → `Context.Provider (value)` → `useTheme()` → `UI Components`

## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
