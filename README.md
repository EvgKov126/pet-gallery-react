# Лабораторна робота №1 — Створення базового React‑застосунку (Vite)

Ця робота демонструє базові кроки зі створення галереї домашніх улюбленців на React за допомогою Vite: ініціалізація проєкту, організація структури папок, налаштування сучасних стилів (Glassmorphism, Grid) та реалізація взаємопов’язаних компонентів: `Header`, `PetCard`, `PetList`.

## Мета

- Освоїти швидку ініціалізацію проєкту на базі Vite.
- Організувати зрозумілу структуру вихідних файлів.
- Налаштувати базові стилі та змінні теми.
- Створити прості статичні компоненти та скласти їх у сторінку.

## Стек і вимоги

- Node.js 20+
- Vite 7
- React 19

## Структура проєкту

```
pet-gallery/
├─ index.html
├─ package-lock.json
├─ package.json
├─ vite.config.js
├─ public/
└─ src/
    ├─ main.jsx            # Точка входу React
    ├─ App.jsx             # Кореневий компонент застосунку
    ├─ index.css           # Глобальні стилі та CSS Grid
    ├─ App.css             # Стилі головного контейнера
    ├─ assets/
    │  └─ logo.svg         # Векторний логотип галереї
    ├─ components/
    │  ├─ Header.jsx       # Компонент шапки з навігацією
    │  ├─ PetList.jsx      # Контейнер для списку карток
    │  └─ PetCard.jsx      # Окрема картка улюбленця
    └─ styles/             # Папка зі стилями компонентів
       ├─ Header.css       # Стилі для Header (Glassmorphism)
       └─ PetCard.css      # Стилі для PetCard (Soft UI)
```

## Приклад реалізації компонентів

- `Header` — містить логотип, що збільшується при наведенні, та навігаційне меню.
- `PetCard` — відображає фото, назву виду та вік. Містить інтерактивну кнопку (`Like`), яка змінює колір та форму SVG-іконки при натисканні.
- `PetList` — отримує масив даних про тварин та динамічно генерує список компонентів (`PetCard`).


## Стилі й тема

Код розбито на окремі модулі для зручності:
`Header.jsx` — верхня частина з логотипом та кнопкою, використовує ефект розмиття фону.

`PetList.jsx` — головний контейнер, який за допомогою сітки (Grid) виводить усі картки.

`PetCard.jsx` — окрема картка з фото, описом та кнопкою «лайк», що має анімацію при наведенні.

Усі компоненти отримують стилі з папки `styles/`, що дозволяє легко змінювати вигляд окремих частин, не ламаючи весь сайт.

## Як запустити локально

1) Встановіть залежності

```powershell
npm install
```

2) Запустіть режим розробки (з HMR)

```powershell
npm run dev
```

Після запуску у консолі зʼявиться локальна адреса (типово http://localhost:5173). Відкрийте її у браузері.

3) Зібрати продакшн‑білд

```powershell
npm run build
```

4) Попередній перегляд зібраної версії

```powershell
npm run preview
```
